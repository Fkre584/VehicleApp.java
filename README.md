Project Description

This Vehicle Management System is a Java-based application designed to showcase the practical application of Inheritance and Polymorphism. The project features a hierarchical structure where a base class, Vehicle, establishes common attributes and behaviors, which are then specialized by subclasses like Car and Truck. By utilizing access modifiers such as protected and private, the system demonstrates effective Encapsulation, ensuring data integrity while allowing flexible extensions. Furthermore, the use of Method Overriding allows each vehicle type to provide its own specific logic for starting the engine, while the final keyword is strategically used to protect core methods from unintended modifications, resulting in a robust and well-organized codebase
